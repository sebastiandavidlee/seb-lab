GD Lab — "Find the Minimum of a Quadratic with Gradient Descent"

This is the known coding question for this loop. Below: the canonical answer, the six follow-ups they actually ask, and a live simulator to build intuition for every regime they can push you into. The derivations behind the \(1/a\) threshold are on the Math page.

1 · The Canonical Pure-Python Solution

For \(f(x) = ax^2 + bx + c\), the gradient is \(f'(x) = 2ax + b\) — say this out loud before typing. Write it clean, with the analytic gradient, a real convergence check, and the input guard:

def minimize_quadratic(a, b, c=0.0, lr=0.1, x0=0.0, tol=1e-8, max_iter=10_000):
    """Minimize f(x) = a*x**2 + b*x + c by gradient descent.

    Gradient: f'(x) = 2*a*x + b.  Requires a > 0, else f has no minimum.
    """
    if a <= 0:
        raise ValueError("a must be positive: f is unbounded below")
    x = x0
    for it in range(max_iter):
        grad = 2*a*x + b
        if abs(grad) < tol:          # converged: slope is flat
            return x, it
        x -= lr * grad               # the update
    return x, max_iter               # ran out of budget — say so

# sanity: minimize_quadratic(1, -4) -> x ≈ 2.0, matches -b/(2a)

Talk track while writing: "gradient is analytic so I don't need autodiff; I stop on gradient norm, not iteration count; I return the iteration count so the caller can tell convergence from budget exhaustion; and I guard \(a \le 0\) because the problem is ill-posed there."

The six follow-ups (they will ask 2–3 of these)

a) "What if I don't give you the gradient?" — numerical differentiation

def num_grad(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2 * h)   # central difference

Why central: Taylor-expand \(f(x\pm h) = f \pm hf' + \tfrac{h^2}{2}f'' \pm \tfrac{h^3}{6}f''' + \dots\) Subtracting, the even-order terms cancel, leaving error \(O(h^2)\); the forward difference \((f(x+h)-f(x))/h\) keeps the \(\tfrac{h}{2}f''\) term, so it's only \(O(h)\). Also mention the floating-point floor: too-small \(h\) amplifies round-off, so \(h \approx \sqrt{\varepsilon_{machine}} \approx 10^{-8}\)–\(10^{-5}\) is the sweet spot.

b) "How do you decide when to stop?" — the criteria menu

  • \(|f'(x)| < \text{tol}\) — first-order optimality; the principled default.
  • \(|x_{t+1} - x_t| < \text{tol}\) — parameter movement; note it equals \(\eta|f'|\), so it's the same test rescaled by lr.
  • \(|f(x_{t+1}) - f(x_t)| < \text{tol}\) — loss plateau; what you actually watch in training.
  • max_iter — the budget backstop; always present, never the only criterion.

Bonus point: absolute tolerances are scale-dependent — for production, use relative (\(|f'| < \text{tol} \cdot (1 + |f|)\)).

c) "What if a < 0?" — detect and refuse

\(f\) is a downward parabola: no minimum exists and GD runs to \(-\infty\). Guard at entry (raise ValueError) — or, if you can't inspect \(a\) (black-box \(f\)), detect it dynamically: the loss increasing monotonically while the gradient magnitude grows is the signature. Never silently return the last iterate.

d) "What happens as I change the learning rate?" — the regimes

Deviation from the vertex obeys \(d_{t+1} = (1 - 2a\eta)\,d_t\) (derivation on Math §1, with \(L = 2a\)):

lr rangemultiplier \(1-2a\eta\)behavior
\(0 < \eta < \tfrac{1}{2a}\)\((0, 1)\)monotone convergence
\(\eta = \tfrac{1}{2a}\)\(0\)one-step exact (Newton step for a quadratic)
\(\tfrac{1}{2a} < \eta < \tfrac{1}{a}\)\((-1, 0)\)oscillating convergence
\(\eta = \tfrac{1}{a}\)\(-1\)permanent oscillation, never converges
\(\eta > \tfrac{1}{a}\)\(< -1\)divergence

e) "Add momentum."

def minimize_momentum(a, b, lr=0.1, x0=0.0, beta=0.9, tol=1e-8, max_iter=10_000):
    x, v = x0, 0.0
    for it in range(max_iter):
        grad = 2*a*x + b
        if abs(grad) < tol:
            return x, it
        v = beta * v - lr * grad     # heavy ball: velocity accumulates
        x += v
    return x, max_iter

f) "How do you know your answer is right?" — closed form

\(f'(x^*) = 2ax^* + b = 0 \Rightarrow x^* = -\dfrac{b}{2a}\), with \(f(x^*) = c - \dfrac{b^2}{4a}\). Assert against it in a test: assert abs(x_hat - (-b/(2*a))) < 1e-6. Saying "of course a quadratic has a closed form — GD is the point of the exercise, so I'll use the closed form as the test oracle" is exactly the right framing.

2 · The Simulator

Everything below runs the actual update x -= lr * (2*a*x + b) (plus v = 0.9*v - lr*grad; x += v for the momentum overlay). The red marker on the lr slider is the divergence threshold \(\eta_c = 1/a\) — cross it and watch.

Cross-check the theory live: set a=2, b=0, x₀=5. Threshold ηc = 1/a = 0.5. At lr=0.45 it hops across the valley but shrinks (multiplier −0.8); at exactly 0.5 it bounces between ±5 forever (multiplier −1); at 0.6 every hop grows 1.4× — divergence. Now flip on momentum at lr=0.6: heavy ball is stable up to η < (1+β)/a = 0.95, so the aqua run spirals in while the blue one explodes.

3 · Follow-up Flight Simulator

Each preset configures the simulator into a state an interviewer steers you toward. Click, run, and rehearse the one-line diagnosis.

  • lr just below threshold (a=2, lr=0.45): probing whether you know oscillation can still converge — "multiplier is −0.8, so it's stable but wasteful; I'd halve the lr."
  • lr exactly at threshold (lr=0.50 = 1/a): probing the boundary case — "multiplier is exactly −1: permanent oscillation between ±x₀, gradient never shrinks, the |grad|<tol check never fires. This is why max_iter must exist."
  • lr above threshold (lr=0.60): probing divergence detection — "each step multiplies the error by 1.4; I'd detect f increasing across iterations and raise/decay the lr."
  • far x₀, tiny lr (a=0.3, lr=0.03, x₀=−6): probing the other failure — "converging, but the multiplier is 0.98; it needs ~500 steps. Slow convergence looks like a bug if your budget is 100 iterations."
  • momentum rescues (a=2, lr=0.6, momentum on): probing whether momentum is just "faster" to you — "heavy ball extends the stability range to (1+β)/a = 0.95, so a step size that diverges for plain GD spirals in with momentum. It's not only acceleration; it changes the stable region."

4 · Pure-Python Idioms Under Pressure

Five patterns that keep whiteboard Python clean when your hands are shaking.

Early-return loops — no flag variables

# yes: return communicates "converged" structurally
for it in range(max_iter):
    if abs(grad) < tol:
        return x, it
    ...
return x, max_iter          # falls through = budget exhausted

# no: done = False ... while not done — extra state to get wrong

f-strings for instant debug traces

if verbose and it % 100 == 0:
    print(f"it={it:5d}  x={x:+.6f}  f={a*x*x + b*x:+.6f}  grad={grad:+.3e}")
# {:+.3e} keeps sign and magnitude visible — divergence is obvious in 3 lines

List-comprehension traces — history without ceremony

xs = [x0]
for _ in range(n):
    xs.append(xs[-1] - lr * (2*a*xs[-1] + b))
ratios = [abs(x2/x1) for x1, x2 in zip(xs, xs[1:]) if x1]  # ≈ |1-2a·lr| each step

Closures for objectives — pass functions, not globals

def make_quadratic(a, b, c=0.0):
    f = lambda x: a*x*x + b*x + c
    df = lambda x: 2*a*x + b
    return f, df                 # gd(f, df, ...) now works for ANY objective

# generalizes the solution beyond quadratics in one sentence

Defensive asserts — encode the invariants

assert a > 0, "no minimum for a <= 0"
assert lr > 0 and tol > 0
x_hat, its = minimize_quadratic(a, b, lr=0.1)
assert abs(x_hat - (-b / (2*a))) < 1e-6   # oracle: closed form

Quiz

Q1. For f(x) = 3x² − 6x, what lr makes GD converge in exactly one step, and to where?

The multiplier is 1−2aη = 1−6η; it is 0 at η = 1/6. One step from any x₀ lands on x* = −b/(2a) = 1. (For a quadratic, η = 1/(2a) is the Newton step: 1/f''.)

Q2. Your GD "converges" to x = 4.999 with a=1, b=−10, tol=1e-8, but the interviewer says the check never fired. What happened?

x* = 5, and the loop hit max_iter first: near the optimum the multiplier shrinks the error geometrically but |grad| = |2x−10| ≈ 0.002 may still exceed tol if the budget is small. Distinguish "converged" from "budget exhausted" in the return value.

Q3. Why is the central difference O(h²) but the forward difference only O(h)?

Taylor: f(x±h) = f ± hf′ + h²f″/2 ± h³f‴/6. In (f(x+h) − f(x−h))/2h the even-order terms cancel, leaving h²f‴/6 leading error; forward difference keeps the hf″/2 term.

Q4. With β = 0.9, how much larger a learning rate can heavy-ball momentum tolerate than plain GD on a quadratic?

Plain: η < 2/L. Heavy ball: η < 2(1+β)/L — a factor of (1+β) = 1.9× larger. The "momentum rescues" preset shows it at lr = 0.6 with a = 2.

Q5. Detect a < 0 without seeing a (black-box f).

Track f across iterates: if f increases monotonically while |grad| grows, you are on a concave objective (or lr way past threshold — distinguish by retrying with a much smaller lr: concave still diverges).
