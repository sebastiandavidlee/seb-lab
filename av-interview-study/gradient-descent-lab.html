Gradient Descent Lab

Drill for the known coding question: "minimize $f(x) = ax^2+bx+c$ by gradient descent, in pure Python." Read the solution, then build intuition on the slider before you're asked to whiteboard it.

1. The question, solved cleanly

Canonical solution
def gradient_descent(a, b, x0=0.0, lr=0.1, tol=1e-8, max_iters=10_000):
    """Minimize f(x) = a*x^2 + b*x + c via gradient descent.

    f'(x) = 2*a*x + b is the analytic gradient. Assumes a > 0 (convex,
    has a unique minimum). Stops when the gradient magnitude drops
    below tol, or after max_iters steps.

    Returns (x_min, iterations_used).
    """
    x = x0
    for i in range(max_iters):
        grad = 2 * a * x + b
        if abs(grad) < tol:
            return x, i
        x -= lr * grad
    return x, max_iters

15 lines, no imports, no numpy. The whole thing is: compute the gradient analytically, step against it, check a stopping condition. Say the analytic gradient out loud before you type it — interviewers want to see you differentiate on the spot, not just recall the loop shape.

Follow-up: numerical gradient via central difference
$$f'(x) \approx \frac{f(x+h) - f(x-h)}{2h}$$

Central difference is $O(h^2)$ accurate vs. $O(h)$ for a one-sided difference ($\frac{f(x+h)-f(x)}{h}$) — the $O(h)$ error terms cancel by symmetry. Use $h \approx 10^{-5}$: small enough for accuracy, large enough to avoid floating-point cancellation from subtracting two nearly-equal function values.

def numerical_grad(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2 * h)

def gradient_descent_numeric(f, x0=0.0, lr=0.1, tol=1e-8, max_iters=10_000):
    x = x0
    for i in range(max_iters):
        grad = numerical_grad(f, x)
        if abs(grad) < tol:
            return x, i
        x -= lr * grad
    return x, max_iters
Follow-up: stopping criteria options
  • Gradient norm (used above): $|\nabla f(x)| < \text{tol}$ — stop when near-flat. Most standard.
  • Function value change: $|f(x_{t+1}) - f(x_t)| < \text{tol}$ — useful when the gradient is noisy but the loss itself is stable.
  • Parameter change: $|x_{t+1} - x_t| < \text{tol}$ — equivalent to gradient-norm criterion here since $\Delta x = -\eta \nabla f$, but generalizes better to settings where the gradient is stochastic.
  • Fixed iteration budget: always run $N$ steps — simplest, used when you need bounded wall-clock time regardless of convergence.
Follow-up: what if $a < 0$?

Then $f$ is concave — a downward parabola with no minimum, only a maximum. Gradient descent will run downhill toward $x \to \pm\infty$ and never converge. Detect it rather than looping forever:

def gradient_descent_safe(a, b, x0=0.0, lr=0.1, tol=1e-8, max_iters=10_000,
                           divergence_bound=1e8):
    if a <= 0:
        raise ValueError("a must be > 0: f is not convex, no minimum exists")
    x = x0
    for i in range(max_iters):
        grad = 2 * a * x + b
        if abs(grad) < tol:
            return x, i
        if abs(x) > divergence_bound:
            raise RuntimeError(f"diverged at iteration {i}, x={x}")
        x -= lr * grad
    return x, max_iters

Two independent failure modes worth distinguishing out loud: $a \le 0$ (no minimum exists — a problem with the objective) vs. $\eta$ too large for a valid $a>0$ (a minimum exists but the step size overshoots it — a problem with the optimizer config, see next).

Follow-up: learning-rate sweep behavior

From the derivation on the Math+Code page: for $f(x)=ax^2+bx+c$, curvature $L=f''(x)=2a$, and the one-step recurrence on the offset from the minimum is $\Delta_{t+1} = (1-\eta L)\,\Delta_t = (1-2\eta a)\,\Delta_t$. So:

  • $0 < \eta < \dfrac{1}{a}$ (i.e. $\eta L < 2$) — monotonic or damped-oscillatory convergence.
  • $\eta = \dfrac{1}{a}$ exactly — $|1-2\eta a|=1$, permanent oscillation between $\pm\Delta_0$, never converges, never diverges.
  • $\eta > \dfrac{1}{a}$ — $|1-2\eta a|>1$, magnitude grows every step, diverges geometrically.

Follow-up: momentum version
def gradient_descent_momentum(a, b, x0=0.0, lr=0.1, beta=0.9,
                               tol=1e-8, max_iters=10_000):
    x, v = x0, 0.0
    for i in range(max_iters):
        grad = 2 * a * x + b
        v = beta * v + grad
        if abs(grad) < tol:
            return x, i
        x -= lr * v
    return x, max_iters

On this quadratic, momentum mostly matters when you're deliberately below the divergence threshold but still oscillating (a stiff, narrow parabola) — it damps the oscillation and gets you to the minimum in fewer steps than plain GD at the same $\eta$.

Follow-up: closed-form check
$$f'(x) = 2ax + b = 0 \;\Rightarrow\; x^* = -\frac{b}{2a}$$
def closed_form_min(a, b):
    if a <= 0:
        raise ValueError("no minimum for a <= 0")
    return -b / (2 * a)

# sanity check any of the iterative versions against this directly:
a, b = 3.0, -12.0
x_gd, _ = gradient_descent(a, b, x0=10.0, lr=0.05)
x_star = closed_form_min(a, b)
assert abs(x_gd - x_star) < 1e-4, (x_gd, x_star)

Always mention this: for a quadratic there's no reason to only show the iterative version — closing the loop with $x^*=-b/2a$ and asserting agreement is the fastest way to show you understand gradient descent is approximating something you could, in this toy case, solve exactly.

3. Pure-Python idioms under pressure

Five patterns worth having cold
  1. Clean loops without numpy — index-free iteration and early return on convergence, not a fixed range with a break flag: 
    for i in range(max_iters):
    grad = 2 * a * x + b
    if abs(grad) < tol:
        return x, i
    x -= lr * grad
  2. f-strings for debug prints — always include the iteration and enough precision to see convergence behavior, not just the final value: 
    print(f"t={i:4d}  x={x:+.6f}  f(x)={f(x):+.6f}  grad={grad:+.6f}")
  3. List comprehensions for tracing a run — capture a trajectory in one line when you need it for a plot or assertion, without polluting the hot loop with side effects: 
    trace = []
x = x0
for i in range(50):
    grad = 2 * a * x + b
    trace.append((i, x, f(x)))
    x -= lr * grad
# or, if you already have a step function:
xs = [x0]
for _ in range(50):
    xs.append(xs[-1] - lr * (2 * a * xs[-1] + b))
  4. Closures for parameterized objectives — build $f$ and its gradient once from $(a,b,c)$ so the descent loop stays generic and testable against different quadratics without rewriting it: 
    def make_quadratic(a, b, c):
    f = lambda x: a * x**2 + b * x + c
    grad = lambda x: 2 * a * x + b
    return f, grad

f, grad = make_quadratic(3.0, -12.0, 5.0)
  5. Defensive asserts near numerical edges — cheap, and it signals you know where things break (a≤0, tol too loose, lr past threshold) without derailing the main solution: 
    assert a > 0, "f is concave, no minimum"
assert lr > 0, "learning rate must be positive"

Terms

  • Gradient descent — iterative first-order optimization: move against the local gradient direction by a fixed or scheduled step size.Related: momentum, Adam (see Math+Code)
  • Learning rate — the step-size multiplier $\eta$ on the gradient; single most consequential hyperparameter for this toy problem.Related: divergence threshold
  • Convergence criterion — the rule that ends the loop: gradient norm, function-value delta, parameter delta, or fixed budget.Related: tolerance (tol)
  • Curvature / L-smoothness — for this quadratic, $L=f''(x)=2a$; it directly sets the safe step-size ceiling $\eta<2/L$.Related: divergence threshold, Hessian (see Math+Code)
  • Momentum — exponentially-averaged gradient history used to damp oscillation and accelerate convergence.Related: Adam
  • Divergence — when $|1-\eta L|>1$, the update magnitude grows every step instead of shrinking.Related: learning rate
  • Central difference — a symmetric finite-difference gradient estimate, $O(h^2)$ accurate vs. $O(h)$ for a one-sided difference.Related: numerical gradient
  • Closed-form solution — here, $x^*=-b/2a$ from setting $f'(x)=0$ directly; use it to sanity-check any iterative implementation.Related: convexity (see Math+Code)
Q: You set a=2, and want the largest learning rate that still guarantees convergence. What's the ceiling, and what do you expect to see right at that value?

Ceiling is $\eta < 1/a = 0.5$ (strictly; the recurrence coefficient $1-2\eta a$ hits exactly $-1$ at $\eta=0.5$). Right at $\eta=0.5$, the trajectory doesn't converge or diverge — it oscillates forever between $x_0$'s two mirrored offsets around the minimum, since $|{-1}|=1$ means the update magnitude neither shrinks nor grows.
