# sebsites

Static pedagogical sites I've built while learning robot-learning. This repo is checked out locally as **`sites/`** (under `~/projects/`); on GitHub it is still named **`seb-lab`**, so the published site remains at https://sebastiandavidlee.github.io/seb-lab/ until you rename the repository on GitHub (which would change the Pages URL).

- `pi05-site/` — π₀.5, from scratch (standalone, six pages, 17 vizs)
- `pi_workshop/` — π₀ → π₀.5 walked tour (earlier version)
- `lerobot-study/` — LeRobot 0.4.4 ↔ 0.5.0 study
- `fast_workshop/` — FAST tokenizer paper walk-through
- `cc-portfolio/` — Crypto Currently YouTuber portfolio dashboard (holdings + actions + verbatim quotes over time, 232 videos)

Pure HTML/JS/CSS. No build step.
