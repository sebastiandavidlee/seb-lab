# sebsites

Static pedagogical sites I've built while learning robot-learning. This repo is checked out locally as `sebsites/`; on GitHub it is still named **`seb-lab`**, so the published site remains at https://sebastiandavidlee.github.io/seb-lab/ until you rename the repository on GitHub (which would change the Pages URL to `/sebsites/`).

- `pi05-site/` — π₀.5, from scratch (standalone, six pages, 17 vizs)
- `pi_workshop/` — π₀ → π₀.5 walked tour (earlier version)
- `lerobot-study/` — LeRobot 0.4.4 ↔ 0.5.0 study
- `fast_workshop/` — FAST tokenizer paper walk-through

Pure HTML/JS/CSS. No build step.
