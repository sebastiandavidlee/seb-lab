How this is built — and what it isn't

The 1,500 dots are training-time latents — the model encodes each Push-T frame into 192 numbers, and we lay them out in 2-D with UMAP so that frames with similar latents land near each other. The clusters come from an unsupervised algorithm (EVoC) run at several depths; thumbnails are sliced from one pre-rendered sprite sheet, and all three views are plain D3 v7 reading a shared selection store — no React, no build step.

Honestly: these clusters are unsupervised — we never told the model what a "phase" is, and the structure is real but diffuse (silhouette ≈ 0.035). Treat this as structure that fell out of next-frame prediction, not as invented or labeled phases. The point of the page is browsing the world model's latent space, not semantic ground truth.
